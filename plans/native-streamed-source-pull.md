## Implemented behavior and validation

The public selected-class command uses current-only, schema-qualified native extraction through the existing service. Promotion checks live dirty documents and synchronous unsubmitted class-view draft metadata. Selected class-view drafts are flushed to their backing document without saving before preflight; unrelated editors are untouched. A bulk disk-update lease coalesces source/test/class refresh while dirty-document guards remain active. Legacy remote baseline import is selected-only, Source/destination-bound and current-version-only. No missing event authorizes a deletion.

TDD regressions cover typed transport, cancellation before/after the native lease, connection loss, a promotion acknowledged after cancellation, native crash outcome uncertainty, live editor drafts and nested refresh leases. Synthetic 30k outcome/permit tests verify bounded notifications/log output and no per-file editor enumeration. A real disposable Unicode seed validates public CLI extraction through the actual extension client (add, repeat/mtime, saved local edit, dirty veto). An isolated full Extension Development Host invokes the actual registered command, verifies add/repeat and real unsaved-document refusal, and captures the running product output. These checks do not measure a 30k native database or prove full-schema streaming.
