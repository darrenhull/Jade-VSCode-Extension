Native contract: https://github.com/darrenhull/Jade-CLI/issues/60. This isolated consumer branch is based on the frozen PR97 head b6b474c; it does not edit that worktree or activate an unfinished native endpoint.

The existing SourceIndexCache interface gains an explicit nativeVersion/request mode. Activation remains unchanged. Shared mode reads the SAME .jade/source-index/v2-N.json shards, validates the owning root/repository/object format/native build identity and digest-bound advisory parser metadata, and delegates bounded advisory updates to source.index.browser.update. JavaScript never writes shared shards, never sends native rows and never uses browsing models as compilation authority. The old constructor mode remains only for the currently released v1 consumer until the whole migration is qualified; shared mode never falls back to that writer.

Packet: the existing service request carries root, parser and updates with repository-relative path, rawSha256 and model/null. Normal result has code0/passedtrue plus accepted/stale path arrays. Limits are128updates,4MiB packet and2MiB model; over-limit data is explicitly reported, not truncated or retried per file. Native-present rows bind browser.rawSha256 to native.hash. Advisory-only .jade rows use their independent top-level rawSha256 and have no native metadata; they never become compile inputs. Conditional model:null clears browser data only. Stale acknowledgements cannot erase a newer in-flight saved update or trigger a whole native refresh.

The original raw-read digest must be supplied in set(uri,{model,rawSha256}); the adapter neither rereads files nor hashes decoded text. Model serialization whitelists existing class/member/type/parameter/UTF16 source-position metadata and strips source bodies. Optional malformed browsing data is isolated from valid native rows. Root-local proofs/bindings are published only after whole-root validation. A successful explicit native cache refresh must invalidate the adapter before reloading; a failed read is not silently retried as a full parse. The adapter returns no invented mtime/size stamp.
